# X-Customize Utility

旧称「X Assist Toolkit」。拡張機能名・フォルダー名を X-Customize Utility に統一し、バージョンを 1.0.0 にリセットしました。

## インストール
`chrome://extensions` → デベロッパーモードON → 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ。x.com を再読み込み。
設定は拡張アイコン、または「📌ピン止め」でX画面右側に埋め込み表示できます。

## 構成
- injected.js : ページ側。Xのレスポンス(Response.json/text)とReact propsを読み取り
- c1_core.js  : 設定・データ保持・取り込み・検索Ban/サジェストバン判定
- c2_ui.js    : 画面の追加・非表示・メニュー・絞り込み等
- rules.json  : 内部確認用の非表示iframeでX検索画面を読むためのヘッダ調整(xdt=1 のiframeのみ)

## 検索の確認方法(別タブなし)
内部API → 失敗時は画面外の非表示iframeでX公式の検索画面を開き、Xクライアント自身が受け取った結果を読み取ります。

## 判定の根拠
- Shadowban Scanner の技術資料 / xai-org/x-algorithm の Under the Hood ラベル定義(公開コード)
- 多くのラベルは「非フォロワーのおすすめ除外」が効果のため、フォロワー視点・自分視点・閲覧設定の影響を考慮
- 直近5件中3件のセンシティブでアカウントラベル化(公開コードの仕様)
- 自分のアカウントは Under the Hood のJSONを取り込むと精度が上がります
