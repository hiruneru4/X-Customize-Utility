# X Customize Utility

x.com（旧 Twitter）向けの Chrome 拡張機能（Manifest V3）。表示のカスタマイズ・各種ショートカット・数値の詳細表示・センシティブ/シャドウバンの判定支援など、X を使いやすくする機能をまとめたユーティリティです。

## インストール
1. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択
3. x.com を開いている場合はタブを再読み込み

設定は拡張機能アイコンのポップアップ、または「📌 ピン止め」でブラウザ右側のサイドパネルに常駐表示できます。ポップアップ右上の「ホワイト / ブラック」で設定画面のテーマを切り替えられます。

## 機能一覧

### 表示・外観
- **日時の表示**: 並び順（時刻が先／日付が先）、時刻の書式（24時間表記）、詳細な日時の追記・置き換え
- **数値を詳細表示**: 省略表記（1.2万 等）を実数で表示
- **いいね/通知のハートを星（⭐）にする**（バーストアニメも金色に連動）
- **アイコンを四角にする**（DM一覧・拡大表示なども含む）
- **画像を常に高画質で読み込む**
- **複数メディアを横スクロールなしで一括表示**（動画・GIFは格子内でそのまま再生）
- **画像の詳細表示でズーム**（画像の上でホイールを上に回すと専用ビューアで拡大）
- **テーマ変更 — Twitter風にする**: X のロゴを青い鳥に、「ポストする」→「ツイートする」、認証バッジを旧Twitterの青バッジ、起動時のロード画面の鳥、favicon、旧Twitter風のアクセントカラー/丸ボタン/フォントをまとめて適用（オン/オフで即時反映）
- **ぼかし（プライバシー）**: 通知欄・使っていないアカウント・鍵垢ポストをぼかし、カーソルを合わせた間だけ解除（濃さ調整可）

### プロフィール・判定
- **誕生日**: 表示／年のみ非表示／非表示、自分のプロフィールのみ非表示、誕生日から年齢をローカル表示
- **「○年○月からXを利用」を非表示**
- **プロフィール上のボタン**: アカウントスコア（リーチ指数）／📈 ER一覧・CSV書き出し／📉 フォロワー・フォローの増減記録／🔍 From検索／🖼 メディア（画像と動画を一緒に一覧）
- **メディアを開いた初回を「画像」にする**
- **ワンクリックでブロック**: ブロックの確認ダイアログを自動でOK（どのブロック導線にも反映）
- **ユーザー名／スクリーンネームのコピー**ボタン
- **関係表示**: 相互・片思い・片思われ・未フォロー・ブロックを、プロフィール／ポスト／一覧／ホバーカードに表示。相互のとき「フォロー中」ボタンを隠すことも可能
- **判定の表示**: プロフィール/ポストのセンシティブ・シャドウバン・検索ban・おすすめ配信の推定を表示（問題がある時のみ表示、自動判定のオン/オフ）

### ポスト
- **ポストへの反応・エンゲージメント率・メディア保存**: 非表示／ポスト下／…メニュー から配置を選択
- **返信の並び順**（関連性／最新／いいね）、**「フォロー中」の並び順**（人気／最新）の既定変更
- **ホームを「フォロー中」で開く**
- **「さらに表示」を最初から展開** / **センシティブラベルを初回に自動展開** / **センシティブのぼかしだけを解除**
- **ブックマーク数の表示** / **🚫「興味なし」ボタン**
- **ポスト詳細にアカウントの場所を表示** / **編集回数を表示**
- **ポストの文字を非表示** / **文字のみのポストを非表示（画像・動画のみ）**
- **ボタンの非表示**: 「画像を編集」(Grok)／「削除」
- **削除しないようにロック**: …メニューの「削除」の下にロックを追加。ロック中はそのポストの削除を無効化（誤操作防止。拡張機能側で一覧・解除・URLからの手動ロックも可能）
- **共有メニューに「ポストの検索チェック」**を追加
- **添付メディアのセンシティブ推定**（投稿画面）: ①X方針（端末内で計算）②Google Cloud Vision ③OpenAI Moderation（②③は利用者のAPIキーで外部送信。既定オフ）

### サイドメニュー
- **左サイドメニューの項目を非表示**: 話題を検索／フォローする／通話／Grok／クリエイタースタジオ／プレミアム／コミュニティ／ビジネス／広告／スペースを作成／記事
- **追加項目**: リスト／ミュートするキーワード／高度な検索／表示／Under the Hood、および**自作項目（メニュー名＋URL）**を、**項目ごとに表示/非表示・表示場所（もっと見る／左サイドメニュー）・並び順**を設定（「リスト」は公式のリスト項目・アイコンを使用）
- **ボタンの非表示**: 「認証される」／認証バッジ／ブースト／Grokボタン
- **右サイドメニュー・タイムラインの非表示**: 検索バー／プレミアム導線／ライブ放送／本日のニュース／「いま」を見つけよう／おすすめユーザー／ホームの「おすすめ」タブ／スクロール中のおすすめ／フッター

### 文字編集
- **定型文**: ツール内で追加・削除し、投稿/返信画面の「📝 書き込み」ボタンから挿入
- **下書き**: ローカル保存（API不使用）。📝 →「📄 下書き」から呼び出し、「💾 今の入力を保存」も可能
- **返信相手の名前を入れる**: 📝 から表示名を本文に挿入
- **高度なミュート**: 語句 / `/正規表現/` / `@ユーザー` / `#タグ` で、一致したポストをタイムライン上で非表示（ローカル）
- **マーカー・下線**: いいね（ピンク）・リポスト（緑）の縦線強調、鍵垢の名前・URL・ハッシュタグのマーカー/下線（色指定可）
- **キーワード強調**: 登録した語句を TL・プロフィール・ポスト・DM でマーカー/下線表示（画面のDOMを書き換えない CSS Custom Highlight API を使用）

### お気に入り
- @スクリーンネームの追加・削除、一覧（アイコン・表示名・@ID）の表示・並び替え
- X 上でお気に入りユーザーの名前の横に **★ または ❤️** を表示（ユーザーごとに一覧で切り替え）
- プロフィールの「…」メニューに「お気に入りに追加/削除」を追加

### 削除ロック
- 「削除しないようにロック」したポストの一覧・解除
- ポストのURL（または ID）からの手動ロック追加

### 統計・情報
- **取得状況（診断）**: API/React/ユーザー/ポスト/エラーの件数で動作状況を確認
- **推移グラフ**（この端末内のみ）: 登録アカウントの ER／フォロワー／センシティブ件数を、折れ線・棒・数字で表示（期間・集計切替）
- **センシティブの記録**: ログイン中アカウントの検知を、@ID・投稿日時・残り時間付きで記録（記録期間を選択、手動追加・削除・全消去）
- **シャドウバンの記録**: 「疑い」を検知したアカウントを記録（解除までの残り時間、手動追加・削除）

### その他
- **セーフモード**: 自動で行う通信をすべて停止
- **設定をすべて初期化**（保存データは残す。2回押しで確定）
- **データのバックアップ**: 定型文・強調・ミュート・各記録・お気に入り・APIキーなどを1つのJSONに書き出し／読み込み
- **スクリーンネーム ↔ ID 変換**
- **Under the Hood**: 公式レポート(JSON)を取り込み、判定の精度を補助

## 構成
- `injected.js` : ページ側（MAINワールド）。X のレスポンスと React props を読み取り
- `c1_core.js` : 設定・データ保持・取り込み・判定ロジック
- `c2_ui.js` : 画面の追加・非表示・メニュー・各種処理
- `background.js` : サービスワーカー（JSバンドル取得・メディア保存・外部AI判定の中継）
- `popup.html` / `popup.js` / `popup.css` : 設定画面（ポップアップ／サイドパネル共通）
- `content.css` : 画面に適用するスタイル
- `rules.json` : 内部確認用の非表示iframeのためのヘッダ調整

## 判定について
- 判定は公開情報（Shadowban Scanner の技術資料、xai-org/x-algorithm の公開コードを第三者が読み解いた内容）に基づく**参考値**で、Xの本番仕様や実際のラベルと一致するとは限りません。
- 多くのラベルは「非フォロワーへのおすすめ除外」として働くため、自分視点では出てしまうことがあります。自分のアカウントは Under the Hood のレポートを取り込むと精度が上がります。
- ②③の外部AIによるセンシティブ推定を使う場合のみ、画像が各社サーバーへ送信されます（APIキーはこのブラウザ内にのみ保存）。それ以外の処理はすべて端末内で完結します。

## 更新履歴
### v1.0.1
- 「メディアを開いた初回を『画像』にする」が、初回だけでなく常に反映されてしまい、手動で「動画／すべて」に変えても画像へ戻ってしまう不具合を修正。開いた初回のみ適用し、以降の手動変更を反映するように修正しました。
- 「文字のみのポストを非表示（画像・動画のみ表示）」を有効にしているとき、通知欄のリプライ／メンションまで消えてしまう不具合を修正。`/notifications` では非表示処理を適用しないようにしました（タイムラインでは従来どおり）。
